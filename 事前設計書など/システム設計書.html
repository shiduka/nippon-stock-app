日本株投資先発掘アプリ システム詳細設計書

1. システム概要・目的

日本株市場（プライム・スタンダード・グロース等）の上場企業データ、日次株価、株主優待データ、および信用取引残高データを完全自動で収集・蓄積するシステム。蓄積したデータをもとに、スマートフォンやPCのブラウザから直感的に銘柄のスクリーニングやチャート分析を行えるWebアプリケーションを提供する。

  • 運用コスト: 完全無料（GitHub Actions, Supabase/DuckDB, Streamlit Community Cloudを活用）
  • 利用環境: モバイル（Android等のスマホブラウザ）ファースト、PCブラウザ対応
  • 開発言語: Python, SQL

2. システムアーキテクチャ構成

【自動データ収集バッチ】 (GitHub Actions)
  │
  ├─ 1. JPX適時開示スクレイピング（毎日） ─> 企業マスター更新（新規上場・廃止・社名変更）
  ├─ 2. 株価API/スクレイピング（毎日）  ─> 日次株価・ストップ高安の取得
  ├─ 3. 優待・決算日情報取得（週1回）   ─> 優待新設/廃止、次回決算予定日の更新
  └─ 4. JPX信用残高CSV取得（週1回）     ─> 信用買い残・売り残の更新
  │
【データストア】 (Supabase PostgreSQL + ローカル同期ファイル)
  │
  ├─ ホットデータ: Supabase (日々の画面検索用)
  └─ コールドデータ: Parquet/DuckDB形式 (週次で全履歴を圧縮・ローカル分析用に出力)
  │
【フロントエンド画面】 (Streamlit Community Cloud)
  └─ スマホ/PCブラウザからアクセス。プリセット条件によるスマート検索とチャート表示

4. バッチ処理・データ自動収集フロー (GitHub Actions)

平日の夜間および週末にスケジュール実行し、全データを自動更新する。

4.1 スケジュール定義

  • ① JPX会社情報巡回: 平日 17:00 (新規上場、上場廃止、社名変更の検知)
  • ② 日次株価収集: 平日 18:00 (直近3日分の差分を取得し、ストップ高安を判定)
  • ③ 週次信用残高収集: 毎週火曜 19:00 (JPXからCSVを取得)
  • ④ 優待・決算巡回: 毎週日曜 02:00
  • ⑤ ローカルバックアップ: 毎週日曜 03:00 (全履歴のParquetファイル出力)
エラーリカバリー仕様（日次株価）:
単一日の取得ではなく「直近3営業日」を常に取得対象とする。前日にエラーでバッチが停止した場合でも、翌日のバッチ実行時に未取得データが自動的に補完される。また、長期間の停止に備え、日付範囲を指定して再取得する手動起動用スクリプト（workflow_dispatch対応）も実装する。

5. 通知設計 (LINE連携)

夜間のバッチ実行時には通知音によるストレスを排除し、毎朝の結果サマリーのみをLINEに送信する。

  • 通知手段: LINE Messaging API (自分宛てプッシュ通知)
  • 夜間処理時: エラーが発生してもログ出力のみ行い、LINE通知は送信しない（サイレント処理）。tenacity ライブラリによる3回の自動リトライで一時的エラーを吸収。
  • 朝のサマリー通知: 毎朝 07:00 に、前夜の全バッチ結果（取得件数、エラーの有無）を1通のメッセージとして送信する。

6. 画面・UI設計 (Streamlit)

スマートフォンでの片手操作を前提とした1カラムレイアウト。上部の4つのタブ（またはセレクトボックス）で画面を切り替える。

6.1 画面タブ構成

  1. タブ1【個別銘柄詳細】: 検索バー（旧社名対応）。直近株価、イベント情報（次回決算日）、インタラクティブチャート（ローソク足、移動平均、出来高、信用残高推移）、優待詳細を縦スクロールで表示。
  2. タブ2【優待スクリーナー】: 権利確定月、ジャンル、最低投資金額などのフィルターを用いて、テーブル形式で優待銘柄を検索。
  3. タブ3【スマート・スクリーナー】: 事前定義されたプリセット条件（例:「🚀 本日のストップ高」「⚡ 信用倍率1倍割れの好取組」「🎁 今月権利確定」）をドロップダウンから選ぶだけで、複雑なSQL条件によるスクリーニング結果を即座に表示。
  4. タブ4【システム管理】: バッチの直近ステータス確認、手動リカバリー実行ボタン、ローカル分析用Parquetファイルのダウンロード。

6.2 プリセット条件管理 (presets.py)

タブ3で使用する検索条件はPythonの辞書形式で管理し、PCでの条件追加・変更を容易にする。

SCREENING_PRESETS = {
    "signal_stop_high": {
        "title": "🚀 本日のストップ高",
        "query": "is_stop_high = TRUE AND status = 'ACTIVE'"
    },
    "margin_squeeze_candidates": {
        "title": "⚡ 信用倍率1倍割れの踏み上げ候補",
        "query": "margin_ratio < 1.0 AND margin_sell_volume > 50000"
    }
}
