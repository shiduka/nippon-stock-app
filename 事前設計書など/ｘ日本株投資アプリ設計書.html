日本株 投資先発掘・分析システム 詳細設計書

バージョン 1.0.0 確定版 作成日: 2026-09-06

1. システム概要・基本方針

1.1 目的

東証上場全銘柄の株価・企業情報・株主優待・需給（信用残高）データを完全無料のインフラ上で日次収集・蓄積し、スマートフォンおよびPCから快適にスクリーニング・分析できるシステムを構築する。

1.2 基本設計方針

  • 完全無料運用: GitHub Actions、Streamlit Community Cloud、Supabase無料枠、LINE Messaging APIの組み合わせでサーバー・データ代0円運用。
  • データの永続性と履歴追跡: 上場廃止企業は論理削除（status='DELISTED'）で保管。社名変更履歴も完全保持し、旧社名からの検索を可能とする。
  • 自己治癒型リカバリー: 日次株価バッチは直近3日間の未取得差分を自動補完し、障害時も手動操作なしで自動復旧。
  • モバイルファースト: スマホでの細かい操作を不要とし、PCで定義した「スマート・スクリーナー」を選ぶだけの軽快検索を実現。

3. 自動バッチ処理・通知設計

バッチスケジュール

  • 平日 17:00: JPX新着巡回（新規上場・上場廃止・商号変更を検知し即座にマスター反映）
  • 平日 18:00: 日次株価収集（直近3営業日自動補完 ＋ ストップ高安判定）
  • 毎週火曜 19:00: JPX公表の信用残高CSV集計・蓄積
  • 毎週日曜 02:00: 株主優待・決算発表日巡回
  • 毎週日曜 03:00: 全履歴Parquetバックアップ出力
  • 毎朝 07:00: LINE朝サマリー送信（夜間は完全無音・エラー時も朝集約）

4. Streamlit 画面設計

4つのタブ構成

  1. タブ1：銘柄検索・個別詳細: コード/社名/旧社名検索、日足チャート(Plotly)、信用残高推移グラフ、優待情報。
  2. タブ2：株主優待スクリーナー: 確定月（今月・来月ボタン）、優待カテゴリ、必要資金による絞り込み。
  3. タブ3：スマート・スクリーナー: スマホ用の事前定義プリセット選択（ストップ高安、信用倍率1倍割れ、つなぎ売り候補等）。
  4. タブ4：システム状況・データ同期: バッチ稼働ステータス確認、手動リカバリー、Parquetダウンロード。
