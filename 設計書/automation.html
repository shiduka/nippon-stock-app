⚡ 自動化バッチ処理一覧

本アプリでは、GitHub Actions を利用して各種データ取得バッチを完全自動化しています。
すべてのバッチは GitHub リポジトリ の .github/workflows/ ディレクトリに YAML ファイルとして定義されています。

各バッチの詳細

📊 Daily Stock Price Batch（日次株価取得）

ワークフロー: .github/workflows/daily_stock_batch.yml
スクリプト: fetch_stock_prices.py
項目内容
スケジュールcron: '0 9 * * 1-5'（UTC 09:00 = JST 18:00、平日のみ）
データソースyfinance（Yahoo! Finance グローバルAPI）
保存先テーブルdaily_stock_prices
保存方式UPSERT（既存データがあれば上書き更新）
取得項目始値, 高値, 安値, 終値, 調整後終値, 出来高, 前日比
💡 東京証券取引所の取引終了後（15:30以降）に実行されるため、その日の確定した終値を取得できます。

💹 Weekly Margin Balance Batch（週次信用残高取得）

ワークフロー: .github/workflows/weekly_margin_batch.yml
スクリプト: fetch_margin_balance.py
項目内容
スケジュールcron: '0 12 * * 2'（UTC 12:00 = JST 21:00、毎週火曜日）
データソースYahoo!ファイナンス 信用残時系列ページ（HTMLスクレイピング）
保存先テーブルmargin_balances
保存方式UPSERT（ticker_symbol + report_date で重複判定）
取得項目売残, 買残, 信用倍率
💡 信用残高データは金曜日時点の数値が翌週火曜日に公開されるため、火曜夜に取得します。
⚠️ HTMLスクレイピングのため、Yahoo!ファイナンスのUI変更時にはスクリプトの修正が必要になる場合があります。

📅 Monthly Earnings Date Batch（月次決算日取得）

ワークフロー: .github/workflows/monthly_earnings_batch.yml
スクリプト: fetch_earnings_dates.py
項目内容
スケジュールcron: '0 11 1 * *'（UTC 11:00 = JST 20:00、毎月1日）
データソースyfinance calendar プロパティ
保存先テーブルcompanies（next_earnings_date カラムを UPDATE）
保存方式UPDATE（企業マスターの該当カラムのみ更新）
取得項目次回決算発表予定日
💡 決算日は頻繁には変わらないため、月1回の取得で十分です。

🎁 Monthly Benefits Batch（月次株主優待取得）

ワークフロー: .github/workflows/monthly_benefits_batch.yml
スクリプト: fetch_benefits.py
項目内容
スケジュールcron: '0 11 15 * *'（UTC 11:00 = JST 20:00、毎月15日）
データソースYahoo!ファイナンス 株主優待ページ（HTMLスクレイピング）
保存先テーブルshareholder_benefits
保存方式DELETE → INSERT（全件洗い替え）
取得項目権利確定月, 最低必要株数, 優待内容の要約
💡 優待の新設・廃止を反映するため、毎回全件を洗い替えて最新化します。
⚠️ HTMLスクレイピングのため、Yahoo!ファイナンスのUI変更時にはスクリプトの修正が必要になる場合があります。

GitHub Secrets（環境変数）

各バッチが Supabase に接続するために、以下の2つの Secret が GitHub リポジトリに登録されています。

Secret 名用途設定場所
SUPABASE_URLSupabase プロジェクトの API URLSettings → Secrets → Actions
SUPABASE_KEYSupabase の公開 API キー（anon key）Settings → Secrets → Actions

手動実行方法

各バッチはスケジュール実行のほか、いつでも手動で実行できます。

  1. GitHub リポジトリの 「Actions」 タブを開く
  2. 左メニューから実行したいバッチ名を選択
  3. 右側の 「Run workflow」 ボタンをクリック
  4. 緑色の「Run workflow」ボタンで実行開始
💡 黄色い丸（処理中）→ 緑色のチェック（成功）/ 赤色のバツ（失敗）で結果を確認できます。

トラブルシューティング

症状原因対処法
バッチが指定時刻に動かない GitHub Actions の cron は世界中のジョブが集中するため、最大1時間遅延することがある 急ぎの場合は手動実行で対応
500 Server Error（一部銘柄） 信用取引非対象銘柄や優待未実施銘柄でYahoo側がエラーを返す 正常動作。該当銘柄はスキップされ、次の銘柄に自動で進む
possibly delisted（一部銘柄） 上場廃止済み or yfinance にデータがない銘柄 正常動作。該当銘柄はスキップされる
スクレイピングで全件0件取得 Yahoo!ファイナンスの HTML 構造が変更された可能性 スクリプト内の正規表現パターンを修正する必要あり
